# UC Merced Super-Resolution Project Guide

## Current workflow

This repository prepares synthetic 4× low/high-resolution pairs from the UC Merced Land Use dataset and trains SRGAN or ESRGAN generators. Bicubic interpolation provides a reference. The active evaluation measures PSNR_Y, SSIM_Y, and LPIPS on the held-out test split.

Prepare the image-level splits and paired data:

```powershell
python -m scripts.prepare_data inspect --config configs/data.yaml
python -m scripts.prepare_data split --config configs/data.yaml
python -m scripts.prepare_data build --config configs/data.yaml
```

Train the two GAN models:

```powershell
python -m training.train_srgan --config configs/srgan_ucmerced.yaml --stage all
python -m training.train_srgan --config configs/esrgan_ucmerced.yaml --stage all
```

The expanded ESRGAN run requests CUDA and uses 12 RRDB blocks, 48 feature channels, 24 growth channels, batch size 4, mixed precision, 20 pixel-warmup epochs, and 40 adversarial epochs. It saves to `checkpoints/esrgan/esrgan_ucmerced_v2/`.

Evaluate the same test split and compare the outputs:

```powershell
python -m evaluation.evaluate --config configs/evaluation_ucmerced.yaml
```

The updated comparison is saved to `results/ucmerced_v2/`, preserving the earlier evaluation. Run 4× inference with the selected trained checkpoint:

```powershell
python -m inference.super_resolve --model esrgan --model-config configs/esrgan_ucmerced.yaml --checkpoint checkpoints/esrgan/esrgan_ucmerced_v2/best_generator.pth --input path\to\lr.png --output results/ucmerced/inference
```

## Reading the metrics

Higher PSNR_Y and SSIM_Y indicate greater pixel and structure agreement. Lower LPIPS indicates closer learned perceptual similarity. ESRGAN is designed to improve perceptual detail, but its name or capacity does not guarantee better results on every dataset or metric. Select based on held-out evaluation and visual review.

## Historical artifacts

The repository retains older CNN checkpoints, metrics, experiment logs, and reports as historical records. The CNN implementation, trainer, configs, inference option, and active evaluation methods have been removed. Older reports describe previous experiments and should not be treated as current UC Merced results.

## Dataset limitations

UC Merced contains 2,100 RGB images of 256×256 pixels. LR inputs in this project are generated by bicubic downsampling, so the scores describe reconstruction under that synthetic degradation and do not establish performance on real sensor LR imagery. GANs can synthesize plausible texture that is not present in the source; metric gains should be checked against visual evidence.
