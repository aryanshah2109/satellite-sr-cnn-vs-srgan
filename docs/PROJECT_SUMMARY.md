# UC Merced Super-Resolution Project Summary

## Scope

This project implements and evaluates 4× single-image super-resolution for the UC Merced Land Use RGB dataset. The active pipeline supports SRGAN and ESRGAN, with bicubic interpolation as the baseline. Evaluation uses PSNR_Y, SSIM_Y, and LPIPS on a held-out test split.

## Current UC Merced results

The current evaluation contains 303 test images. Higher PSNR_Y and SSIM_Y are better; lower LPIPS is better.

| Method | PSNR_Y | SSIM_Y | LPIPS |
|---|---:|---:|---:|
| Bicubic | 25.5902 ± 4.3936 | 0.6948 ± 0.1306 | 0.4808 ± 0.1313 |
| SRGAN | **26.3456 ± 3.9112** | **0.7339 ± 0.1348** | **0.1752 ± 0.0948** |
| ESRGAN | 25.3301 ± 3.9541 | 0.6910 ± 0.1335 | 0.1982 ± 0.0860 |

### Interpretation

- SRGAN is the strongest current model across all three reported metrics.
- Relative to bicubic, SRGAN improves PSNR_Y by about 0.76 dB, SSIM_Y by about 0.039, and substantially reduces LPIPS.
- ESRGAN is not competitive with SRGAN on this test split: it is below bicubic on PSNR_Y and SSIM_Y, and its LPIPS is higher than SRGAN's.
- The results support selecting SRGAN for the current UC Merced workflow. ESRGAN may need additional tuning, a different training schedule, or a better-matched checkpoint before it can be preferred.

## Important limitations

- LR images are generated by bicubic downsampling, so the results do not establish performance on real sensor imagery.
- GAN models can hallucinate plausible texture that is not present in the source image; visual inspection remains necessary.
- The current environment contains a CPU-only PyTorch build (`torch 2.14.1+cpu`). The NVIDIA RTX 4050 and driver are visible to Windows, but CUDA inference requires reinstalling a CUDA-enabled PyTorch wheel.
- Historical `results_final/` metrics describe an earlier satellite-image experiment and should not be mixed with the current UC Merced table.

## Reproduction commands

From the `Main` directory:

```powershell
.\.venv\Scripts\python.exe -m evaluation.evaluate --config configs/evaluation_ucmerced.yaml
```

SRGAN inference:

```powershell
.\.venv\Scripts\python.exe -m inference.super_resolve `
  --model srgan `
  --model-config configs/srgan_ucmerced.yaml `
  --checkpoint checkpoints/srgan/srgan_ucmerced/best_generator.pth `
  --input path\to\low_resolution_image.tif `
  --output results/ucmerced/inference `
  --device cuda `
  --amp
```

ESRGAN inference:

```powershell
.\.venv\Scripts\python.exe -m inference.super_resolve `
  --model esrgan `
  --model-config configs/esrgan_ucmerced.yaml `
  --checkpoint checkpoints/esrgan/esrgan_ucmerced_v2/best_generator.pth `
  --input path\to\low_resolution_image.tif `
  --output results/ucmerced/inference `
  --device cuda `
  --amp
```

The generated filename follows the pattern `<input_stem>_x4.png`.
